# KitNote v0.1.1

Release date: June 24, 2026

KitNote v0.1.1 is a small post-release update to the first Tauri-based KitNote test release. It remains an early pre-release intended for testing.

## Changes

- Note titles are now editable. Double-click the title in the top toolbar, type a new title, then press Enter or click elsewhere to save it.
- Pressing Escape while editing cancels the rename.
- Empty titles fall back to `Untitled note`.
- Titles remain per-note and are saved with the existing local note data.
- Fresh notes now use the soft sticky-note yellow `#FFF4A8`.
- Existing saved note colors are preserved, including notes previously changed to blue.
- New notes created with `+` still inherit visual settings from the source note and start with the title `Untitled note`.
- Added the MIT License, copyright 2026 Ziyi Zhang.

## Data Reset

Changing the default color affects new or fresh notes, but existing persisted notes keep their saved color.

To reset local test notes:

1. Close every KitNote window.
2. Back up `%APPDATA%\com.kitnote.desktop\notes.json` if any notes should be kept.
3. Delete only `%APPDATA%\com.kitnote.desktop\notes.json`.
4. Start KitNote again to create a fresh yellow note.

## Known Limitations

- This is an early test release and is not digitally signed.
- Markdown and TeX editing remain basic.
- Image and hyperlink workflows are still early.
- There is no system tray workflow for reopening closed note windows.
