# KitNote v0.2.0

Release date: June 24, 2026

KitNote v0.2.0 is an early pre-release focused on the writing experience. It replaces the separate Edit and Preview modes with a cursor-aware CodeMirror 6 Live Preview editor.

## Changes

- Removed the normal Edit/Preview mode split.
- Added cursor-aware Live Preview while preserving plain Markdown/TeX as the saved source.
- Added live rendering for inline math, block math, bold, italic, headings, inline code, fenced code, links, lists, and blockquotes.
- Syntax remains raw while the cursor or selection is inside, touching, or adjacent to its source range.
- Clicking rendered content reveals its source for editing.
- Invalid TeX remains visible with a warning style instead of crashing the editor.
- Preserved CodeMirror undo/redo, selection, copy/paste, and keyboard editing behavior.
- Settings now close when clicking outside the popover or pressing Escape.
- Documented the current note-data location and deferred configurable storage migration until it can include backup, validation, and rollback.

## Current Data Location

On Windows, KitNote normally stores user data under:

```text
%APPDATA%\com.kitnote.desktop\
```

See [`docs/data-location.md`](../data-location.md) for the file layout and planned migration design.

## Known Limitations

- Live Preview intentionally covers a focused Markdown subset.
- Tables, task-list controls, footnotes, and complex nested Markdown may remain raw or render only partially.
- Rendered links open with `Ctrl+click`; a normal click reveals their Markdown source.
- Unfinished `$` or `$$` delimiters remain raw.
- Very large notes may render fewer inactive regions until CodeMirror finishes incremental parsing.
- Image insertion remains file-picker-first, and images do not yet support direct manipulation.
- Configurable note-data location is not implemented in this release.
- This early test release is not digitally signed.
