# KitNote v0.1.0

Release date: June 24, 2026

KitNote v0.1.0 is the first lightweight Tauri-based test release of KitNote. It supports floating sticky notes, always-on-top behavior, hidden edge toolbars, rounded and transparent note styling, draggable and resizable notes, multi-note creation with inherited settings, and Windows packaging.

This is an early test release, not a final stable product. Back up important note data before testing.

## Main Features

- Lightweight Windows desktop application built with Tauri v2, React, TypeScript, and Rust.
- Borderless, always-on-top sticky-note windows with configurable transparency and rounded corners.
- Notes can be moved and resized from edges and corners.
- Hidden top and bottom toolbars appear on hover.
- The `+` button creates another note beside the source note without copying its text.
- New notes inherit the source note's visual settings and remain independently usable.
- Markdown editing and preview with basic TeX rendering through KaTeX.
- Local JSON persistence for notes and copied image assets.
- Image selection and web or local-file link insertion.
- Windows NSIS and MSI packaging when the required local build tools are available.

## Install

1. Download the NSIS installer `.exe` or MSI `.msi` from the release page.
2. Run the downloaded installer.
3. Follow the Windows installation prompts.
4. Launch KitNote from the Start Menu or an installer-created shortcut.

Windows may show an unrecognized publisher warning because this early test release is not code-signed.

## Uninstall

1. Open Windows **Settings**.
2. Go to **Apps > Installed apps**.
3. Find **KitNote** and select **Uninstall**.

Local note data may remain under `%APPDATA%\com.kitnote.desktop` after uninstalling. Remove that folder only if the notes are no longer needed.

## Known Limitations

- This is an early test release and has not been broadly tested across Windows configurations.
- Markdown and TeX editing are functional but still basic.
- Image insertion works through the file picker; drag and drop depends on Windows WebView path support.
- Inserted images render in preview but do not yet support full direct manipulation.
- Hyperlink handling is early, and risky executable or script-like local links are blocked.
- Settings and note-recovery workflows are still early.
- There is no system tray workflow for reopening a note after its window is closed.
- The application and installers are not digitally signed.
- MSI generation depends on the required Windows installer tooling being available.

## Data Location

KitNote stores private note data locally:

```text
%APPDATA%\com.kitnote.desktop\notes.json
%APPDATA%\com.kitnote.desktop\assets\
```

These files are not part of the application installer or source repository.
