# KitNote v0.2.1

Release status: prepared for testing; not yet tagged or published.

This release improves KitNote's editor, startup behavior, and security.

## Highlights

- Upgraded the editor to Live Preview so supported Markdown and TeX formulas render while writing.
- Improved inline-math active ranges, including formulas inside list-like source text.
- Stabilized list editing by keeping list markers source-like and using plain newlines, so following text is not hidden or unexpectedly indented.
- Restores only note windows left visible at the end of the previous session, with a non-empty fallback when every note was closed.
- Hardened local file and link opening with allowlist-based handling that blocks risky Windows extensions and network, UNC, and device-like targets.
- Improved persistence safety with single-instance protection, interprocess locking, stale-write rejection, backups, corrupt-file preservation, and save-before-close behavior.
- Narrowed Tauri capabilities to the window, event, and dialog operations KitNote currently uses.

## Notes

- This remains an early, unsigned pre-release build.
- List rendering is intentionally conservative and source-like for editing stability.
- Live Preview supports a focused Markdown subset; some complex Markdown remains raw or partially rendered.
- Notes remain local plaintext in `%APPDATA%\com.kitnote.desktop\`.
