# KitNote Roadmap

- Richer WYSIWYG Markdown editing.
- Better image dragging, resizing, and layout controls.
- Search across notes.
- Tags and note groups.
- Tray icon and hidden-note restore menu.
- Import and export.
- SQLite migration for larger note collections.
- Optional encrypted local backup.
- Optional encrypted sync.
- Plugin system.
- Auto-update support.
- More complete keyboard shortcuts.
- Safer confirmation UI for risky local file links.
